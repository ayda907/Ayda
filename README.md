# ماشین حساب ساده با پایتون 🧮

این یک پروژه آموزشی است که یک ماشین حساب ساده تحت خط فرمان (CLI) را با استفاده از زبان پایتون پیاده‌سازی می‌کند.

## ویژگی‌ها
- پشتیبانی از چهار عمل اصلی ریاضی: جمع، تفریق، ضرب و تقسیم.
- دریافت ورودی‌های پی‌درپی تا زمانی که کاربر درخواست خروج (q) دهد.
- مدیریت خطای تقسیم بر صفر و جلوگیری از توقف برنامه.
- مدیریت خطای ورود مقادیر غیر عددی (استفاده از try-except).

## نحوه اجرا
برای اجرای این برنامه، نیازی به نصب کتابخانه جانبی نیست. تنها کافیست پایتون روی سیستم شما نصب باشد.
فایل اصلی را با اجرای دستور زیر در ترمینال اجرا کنید:


python  ayda.py
